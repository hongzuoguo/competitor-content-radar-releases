# 对标内容雷达使用说明

[下载最新版 Windows 安装包](https://github.com/hongzuoguo/competitor-content-radar-releases/releases/latest)

抖音对标作品采集、转写、爆款判断与 AI 拆解桌面工具

## 工具简介

对标内容雷达帮助个人创作者整理公开抖音作品：采集近期发布内容、识别值得关注的爆款、生成本地转写，并提供 AI 拆解建议。它适合内容研究与创作参考，不替代平台规则判断或版权授权。

使用前请确认你有权访问和使用相关公开内容，并遵守抖音及其他平台的服务规则、隐私要求和内容版权要求。

## 安装包内置内容

- 桌面应用：安装完成后，从开始菜单或桌面快捷方式打开“对标内容雷达”。
- SenseVoice 本地语音识别模型：用于把已获取的视频语音转成文字；正常使用时不需要另行下载或配置。
- FFmpeg：用于处理视频中的音频；它随安装包提供，无需单独安装。
- 本地采集与解析能力：用于读取你选择的公开抖音作品信息，并在应用内完成整理。
- 本地数据库：保存博主、作品、任务记录和分析结果，方便下次继续查看。

## 系统要求与安装

- 系统要求：使用 64 位 Windows 10 或 Windows 11，并预留至少 2GB 可用磁盘空间。
- 安装步骤：双击安装包，按安装向导选择安装位置；完成后勾选或点击“启动对标内容雷达”。
- 出现 Windows 安全提示时：先确认安装包来自你信任的发布渠道，再选择“更多信息”中的继续安装选项；不确定来源时请停止安装。

## 首次配置

- 登录抖音：首次启动会进入设置向导。在“连接抖音账号”步骤点击“打开抖音登录窗口”，按抖音页面提示扫码或完成验证，然后返回应用点击“我已完成登录”。
- 选择 AI 服务：在“选择 AI 拆解模型”步骤选择“AI 提供商”和“模型”。AI 仅用于作品拆解；本地转写无需额外设置。
- 保存 API Key：在“API Key”输入框粘贴你从所选服务商获得的密钥，点击“保存并继续”。请勿把密钥发送给他人、写入公开文档或截图分享。
- API Key 已保存时：设置页会显示“API Key 已保存”。输入框留空并保存不会清除或修改原密钥；只有输入新密钥并保存才会替换。
- 飞书功能状态：当前版本暂不提供飞书同步，相关入口属于后续功能预留。飞书不可用不影响本地采集、转写、爆款判断和 AI 拆解。

## 如何复制博主主页链接

添加博主时需要使用对方的博主主页链接或博主名片分享内容，不要复制某一条视频的分享链接。

1. 手机端：在抖音中打开目标博主主页，点击右上角“···”，进入操作页面后点击“分享名片”。
1. 在随后打开的分享页面中点击“复制链接”。
1. 复制完成后回到“对标内容雷达”，打开“博主管理”，点击“添加博主”，把复制的链接粘贴到输入框。
1. 如果抖音复制出一整段“打开抖音搜索，查看 TA 的更多作品”之类的分享文字，可以整段粘贴，应用会自动提取其中的主页链接。
1. 电脑端：在抖音网页版打开目标博主主页，点击页面右侧的“分享主页”，再点击分享面板底部的“复制链接”，然后粘贴到应用中。
1. 提交前检查：链接应指向博主主页或博主名片；如果内容只描述某一条作品并带有单条视频地址，请返回博主主页重新复制。

## 主要功能

- 博主管理：在“博主管理”页点击“添加博主”，粘贴完整的抖音博主主页地址；可暂停不再需要监控的博主。
- 近期作品采集和去重：首次添加博主会建立近期作品基线，后续运行会跳过已经记录过的作品，减少重复处理。
- 爆款雷达：应用会结合绝对高点赞和相对历史表现标出“爆款”或“相对爆款”，供你优先查看。
- 本地转写：对可处理的作品自动生成语音文字稿，便于检索、阅读和复盘；该步骤不消耗大模型 Token。
- AI 五项拆解：在“作品分析”中查看选题、钩子、结构、爆点和差异化创作建议；结果仅作创作参考。
- 手动导入：在“作品分析”页点击“导入作品”，可上传本地视频，或选择“抖音分享”后粘贴单条公开作品的分享内容或链接。
- 任务记录：在“任务记录”页查看每次运行的进度、完成情况和可采取的下一步操作。
- 每周报告（预留功能）：当前版本尚未提供完整的周报查看、导出和同步能力，设置页中的“每周报告”仅为后续功能预留，请暂时不要依赖。
- 飞书同步：当前版本暂不可用，后续版本加入后再提供配置和同步说明；现有本地历史数据会继续保留。

## 运行、更新与拆解规则

- 新增博主：添加成功后，应用会自动为该博主执行一次首次采集，用近期公开作品建立数据基线，无需再单独点击运行。
- 日常更新：当前版本没有每日自动采集。以后要刷新作品和点赞、评论、收藏、转发等数据，需要点击顶部“立即运行”。
- 一次更新全部博主：点击一次“立即运行”会处理所有处于启用状态的博主，不需要逐个博主点击。
- 暂停的博主：暂停后不会参加下一次手动运行，但已经采集的作品、文字稿和分析结果仍保留在本机。
- 作品去重：已经记录过的作品不会被重复创建；再次运行时会补充新作品，并更新已有作品的互动数据。
- 运行条件：应用关闭、电脑关机或休眠时不会采集。恢复使用后，打开应用并点击“立即运行”即可补更。
- 每周报告：当前属于预留功能，不作为正式的数据更新方式。日常使用只需关注新增博主后的首次采集和顶部“立即运行”。
- 自动拆解对象：应用先按爆款规则筛选作品，再对符合条件且尚未拆解的作品执行 AI 拆解；不符合爆款条件的作品仍会保留数据和文字稿，可在作品详情中手动拆解。
- 拆解数量：设置中的“每位博主最多拆解”表示单次运行中，每位博主最多自动拆解多少条符合条件的作品，默认 10 条。
- 发布时间范围：设置中的“发布于最近”表示只自动拆解该天数范围内发布的作品，默认最近 30 天。
- 避免重复消耗：已经完成 AI 拆解的作品不会再次自动拆解，也不会重复占用当次拆解数量或 AI 服务额度。

## 爆款判断规则

作品满足以下任意一项，就会进入爆款范围并成为自动拆解候选。阈值可在“设置”页调整，修改后影响之后的判断。

- 绝对高点赞：作品点赞达到设定值即视为爆款。默认阈值为 10,000 点赞，适合识别整体表现一直较高的博主作品。
- 相对表现倍数：将当前作品总互动与该博主近期作品的日常互动基线比较。默认达到 1.5 倍即视为相对爆款。
- 相对判断需要样本：至少需要 5 条历史作品形成基线，基线参考该博主最近最多 30 条作品的互动中位数，避免少量异常值干扰。
- 满足任意条件即可：作品不需要同时达到 10,000 点赞和 1.5 倍相对表现；符合其中一项即可进入爆款范围。
- 数据会随运行更新：点赞和互动变化只有在点击“立即运行”重新采集后才会反映到爆款判断和内容雷达中。

## 推荐使用流程

1. 在“设置”或首次向导中完成“AI 提供商”“模型”和“API Key”的配置。
1. 点击“打开抖音登录窗口”登录抖音账号，并在出现验证码或安全验证时按平台提示手动完成。
1. 打开“博主管理”，点击“添加博主”，粘贴需要研究的抖音博主主页地址；添加后会自动执行首次采集。
1. 以后需要更新全部启用博主时，点击顶部“立即运行”，等待采集、转写和分析完成；处理中可在“任务记录”查看状态。
1. 打开“作品分析”，优先筛选或查看标记为“爆款”的作品，再阅读转写和 AI 拆解。
1. 需要查看最新数据时，以“总览”和“作品分析”为准；每周报告和飞书同步均为后续预留功能。

## 数据和隐私

- 本地优先：博主、作品、转写、任务记录和分析结果默认保存在这台电脑上。
- 密钥保护：保存的 API Key 使用 Windows 安全存储保护；界面不会展示完整密钥。
- 联网范围：登录抖音、获取公开作品、AI 拆解和自动更新需要联网；本地转写通常使用安装包内置模型，只有内置模型和本地缓存都不可用时，才会联网下载或补全模型。
- 卸载行为：卸载应用默认保留用户数据，便于日后重新安装继续使用；如需清除，请先确认不再需要历史记录。

## 已知限制

- 抖音的登录状态、验证码和风控可能导致部分采集暂时失败；应用不会绕过平台安全验证。
- AI 拆解需要网络连接，并可能由所选 AI 服务商收取费用；请以服务商账单和额度规则为准。
- 本地转写不消耗大模型 Token，但处理时会占用电脑的处理器、内存和磁盘空间，较长视频需要更多时间。
- 电脑关机、休眠或网络中断期间，任务无法继续运行；恢复后可在“任务记录”查看结果并重新发起。
- 当前版本不会每天自动采集，只有添加博主后的首次采集和点击“立即运行”会刷新抖音作品数据。
- 每周报告当前只是预留功能，尚未提供完整的查看、导出和同步流程，请不要把它当作正式功能或数据更新依据。
- 飞书同步当前不可用，相关能力计划在后续版本加入；本地功能可以独立使用。
- 自动更新需要能够访问 GitHub；受网络环境、代理或发布节奏影响，更新提示可能不会立即出现。

## 常见问题

- 采集失败怎么办？先在“设置”点击“打开浏览器登录”，确认登录和安全验证已完成，再回到顶部点击“立即运行”。
- 本地转写不可用怎么办？确认安装没有被安全软件拦截、磁盘空间充足，然后重启应用重试。应用会优先使用安装包内置模型，并在可用时尝试本地缓存或在线补全。
- AI 拆解失败怎么办？在“设置”检查“AI 提供商”“模型”和 API Key 是否正确，并确认所选服务商的账户余额或额度可用。
- 为什么今天的新作品没有出现？当前版本不会每日自动采集，请点击顶部“立即运行”。一次运行会更新全部启用博主，不需要逐个操作。
- 怎样复制博主主页链接？手机端在博主主页点击右上角“···”，进入操作页面后点击“分享名片”，再在分享页面点击“复制链接”；电脑端点击“分享主页”后选择“复制链接”。
- 为什么添加成了单条作品？你可能复制了视频链接。请回到对方的博主主页重新复制主页链接或名片分享内容，再添加博主。
- 每周报告现在能用吗？当前只是预留功能，尚未提供完整的查看、导出和同步能力。请以“立即运行”更新数据，并在“总览”和“作品分析”查看结果。
- 为什么只自动拆解部分作品？自动拆解只处理符合爆款规则、位于设定发布时间范围内且尚未拆解的作品，并受“每位博主最多拆解”数量限制。
- 飞书现在能用吗？当前版本暂不提供飞书同步，后续版本加入后再开放；这不会影响现有本地数据和其他功能。
- 为什么没有看到爆款？爆款判断需要足够的近期作品作为对比；继续添加符合条件的公开作品并运行后，再回到“作品分析”查看。

## 自动更新

应用会在可访问更新服务时检查新版本。看到更新提示后，先完成正在进行的任务，再按提示下载、安装并重启应用。更新不会默认删除本地博主、作品、设置或分析记录。

如果长期没有收到更新提示，可检查网络是否能访问 GitHub，并从可信发布页确认是否已有新版本。
